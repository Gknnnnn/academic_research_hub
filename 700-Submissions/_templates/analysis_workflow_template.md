# Submission Project Template

Use this template to structure each active submission; `scripts/create_submission_from_promotion.py` otomatik olarak bu yapıyı çoğaltır:

- `data/`: symlinked input datasets (point back to `400-Data/`)
- `code/`: R/Python scripts plus `run.sh`
- `output/`: tables, figures, automated markdown summaries
- `manuscript/`: LaTeX/Word sources
- `submission/`: cover letter, final PDF, supplementary
- `reviews/`: editor/reviewer correspondence
- `revision/`: change logs versus reviews
- `timeline.md`: key dates
