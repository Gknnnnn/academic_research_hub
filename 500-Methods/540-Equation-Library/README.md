# Equation Library

Bu klasör, literatürde tekrar eden model ve denklem iskeletlerini toplar.

Amaç:

- makalelerdeki denklem yapılarını standart hale getirmek
- aynı modeli tekrar tekrar sıfırdan kurma ihtiyacını azaltmak
- Wolfram Alpha, R, Python veya LaTeX tarafında yeniden üretilebilir formüller sağlamak

Alt alanlar:

- `panel-data`
- `time-series`
- `machine-learning`

Kural:

- her denklem notu bir yöntem ailesine bağlanır
- denklem notu ile `150-Method-Maps` notu birbirine link verir
- denklem önce yalın metinle yazılır, sonra LaTeX biçimi eklenir
