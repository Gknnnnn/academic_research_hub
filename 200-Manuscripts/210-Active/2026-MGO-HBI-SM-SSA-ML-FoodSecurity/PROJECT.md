# HBI + Spillover + ML Food Security — SSA
## Objective
Integrate human behavioral index, spatial spillovers, and ML to predict food security vulnerability.
## Data
Sub-Saharan Africa districts (20+ countries), HBI surveys + NDVI + rainfall + prices, 2010-2023.
## Methodology
1. HBI construction (5-dim PCA) + spatial lag
2. Random Forest + SHAP feature importance
3. Vulnerability index prediction (food intake score → ML classification)
## Output
Q1 food security / development journal; policy-brief for African AU.
## Status
Stage 2: Data assembly (HBI surveys + NDVI harmonization).
