# Konya HBI Agricultural Floor — Full GTHK
## Objective
Comprehensive human behavioral index (HBI) analysis of Konya agricultural productivity floor.
## Data
Konya province household + farm surveys (GTHK full-text access), 2015-2023.
## Methodology
1. Principal Component Analysis (HBI construction, 5 dimensions)
2. TWFE + Demeaned estimation
3. Spatial dependence (Pesaran CD test)
## Output
Q1 regional development / agricultural journal.
## Status
Stage 4-5: Full text GTHK data available; analysis framework set up.
