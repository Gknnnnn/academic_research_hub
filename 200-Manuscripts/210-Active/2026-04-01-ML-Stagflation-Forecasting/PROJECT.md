# ML Stagflation Forecasting
## Objective
Predict global stagflation episodes using hybrid Random Forest and SHAP explainability.
## Data
28-country panel, 2004-2024; 46 stagflation observations (Inf>7%, GDP<3%).
## Methodology
1. Random Forest model (R²=0.977 stable / 0.60 stagflation)
2. SHAP interpretability analysis
3. Phillips Curve benchmark
