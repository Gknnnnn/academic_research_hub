# AI Index & Green Transformation — Income Heterogeneity
## Objective
Estimate AI-emission elasticity heterogeneity across income groups; Jevons Paradox.
## Data
41 economies, 2011-2023; AI index + CO2 emissions (WDI).
## Methodology
1. CIPS/Pesaran CD cross-section dependence
2. CS-ARDL + AMG pooling
3. Dumitrescu-Hurlin causality (bootstrap)
4. Quantile-on-Quantile regression
## Output
Q1 panel journal (heterogeneous AI-environment nexus); 23-item bibliography.

Stage 5: v02 complete, v03 in progress; renders without errors.
