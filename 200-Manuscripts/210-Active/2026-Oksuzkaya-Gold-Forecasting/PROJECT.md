# Gold Forecasting — Oksuzkaya Collaboration
## Objective
Develop machine learning ensemble for gold price nowcasting (real-time).
## Data
Daily gold, FX, equity indices, VIX, yield curve, 2010-2024.
## Methodology
1. Random Forest + Gradient Boosting ensemble
2. SHAP feature importance tracking (time-varying)
3. Real-time forecast accuracy (Theil-U, direction accuracy)
## Output
Q1/Q2 finance/forecasting journal; co-authored with Oksuzkaya.
## Status
Stage 3: Baseline RF model; hyperparameter tuning in progress.
