# Currency Wars & Gold — Quantile-on-Quantile Asymmetry
## Objective
Quantify asymmetric currency war effects on gold prices across quantile distributions.
## Data
Daily gold/FX data (2000-2024); EM currency depreciation episodes.
## Methodology
1. Quantile-on-Quantile (QQ) regression
2. Asymmetric error correction model
3. Rolling window analysis of tail dependence
## Output
Q1 financial econ/commodity journal; asymmetric evidence.
