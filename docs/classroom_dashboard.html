💬 Feedback Ladder System — LLM-in-Education Pattern
Based on "Generating Feedback-Ladders for Logical Errors" (ICER 2024) — graduated feedback without giving away the answer.
📐 Econometrics: "Why is OLS biased when regressors are endogenous?"
1
Directional Hint: Think about the Gauss-Markov assumptions. Which one does endogeneity violate, and why does this cause a problem?
2
Scaffolded Hint: If E[u|X] ≠ 0, the error term is correlated with X. Draw a DAG: what path does this create between X and the outcome that OLS cannot separate?
3
Corrective Feedback: OLS is biased because Cov(X,u) ≠ 0 — the estimator picks up the endogenous component. The fix: use an instrument Z such that Cov(Z,X) ≠ 0 but Cov(Z,u) = 0 (relevance + exclusion).
🌍 Makroekonomi: "Türkiye'de enflasyon neden kalıcı?"
1
Directional: Enflasyon beklentileri nasıl oluşuyor? Merkez bankası güvenilirliği bu beklentileri nasıl etkiler?
2
Scaffolded: Döviz kuru geçişkenliği (exchange rate pass-through) yüksek olduğunda, TL değer kaybı doğrudan enflasyona nasıl yansır? Buna Fischer etkisini ekle.
3
Corrective: Türkiye'de enflasyon kalıcılığı: (1) yüksek dolarizasyon → kur geçişkenliği, (2) uyarlanmış beklentiler → fiyat-ücret sarmalı, (3) maliye açıkları → parasallaşma baskısı. AMG modelleri lnERE → CPI β≈0.4 bulmuştur.
